SysMedic 🩺

طبيب لنظام لينكس — يفحص، ويشخّص، ويشرح بلغة بسيطة، ويصف إصلاحات آمنة، ثم يتابع الحالة.

تنزيل المصدر على GitHub دليل التثبيت
الفحصدرجة صحية من 0 إلى 100 لنظامك كاملاً.
التشخيص27 قاعدة تكتشف المشاكل الحقيقية.
الشرحبالعربية والإنجليزية، دون إنترنت.
الوصفةإصلاحات آمنة قابلة للتراجع عبر polkit.
المتابعةفحوص مجدولة وتنبيهات.

شاهده

لماذا SysMedic؟

كل الأدوات الموجودة إمّا مراقب (htop وbtop وMission Center) أو منظّف (BleachBit وStacer) أو أداة خبراء في الطرفية (systemd-analyze وsmartctl). لا أحد يشخّص ويشرح ويصلح بأمان. يقوم SysMedic بخطوات زيارة الطبيب الخمس — ولا يعمل كـ root أبداً: الإصلاحات المميّزة تمر عبر مساعد مُصرَّح له من polkit يقبل معرّف الإصلاح فقط ويعيد بناء الخطة بنفسه، فلا يمكن حقن أي أمر.

واجهة التطبيق والفئات والتقدير والعلاجات وحوار تأكيد الإصلاح مترجمة للعربية؛ عناوين النتائج ما تزال بالإنجليزية حتى اكتمال الانتقال إلى gettext.

  • درجة صحية موزونة من 0 إلى 100
  • المعالج والذاكرة والأقراص والحرارة والبطارية
  • صحة الأقراص SMART وتآكل SSD
  • الخدمات والعمليات وتحليل الإقلاع
  • تدقيق أمني: الجدار الناري وSSH والمنافذ المكشوفة
  • شروحات ثنائية اللغة دون إنترنت (ar/en)
  • إصلاحات آمنة مع معاينة وتراجع
  • محلّل خريطة استخدام القرص
  • فحوص مجدولة وتنبيهات سطح المكتب
  • تقارير HTML / Markdown / JSON / PDF
  • شرح معمّق اختياري بالذكاء الاصطناعي (بمفتاحك الخاص)
  • GTK4/libadwaita — داكن/فاتح تلقائياً

جرّب سطر الأوامر

sudo apt install ./sysmedic_*.deb

sysmedic checkup                       # تقرير ملوّن من 0 إلى 100
sysmedic explain storage.disk_nearly_full --lang ar
sysmedic explain storage.disk_nearly_full --deep   # اختياري: ذكاء اصطناعي
sysmedic fix fix.apt_clean --dry-run   # معاينة إصلاح آمن
sysmedic disk ~                        # أكبر المجلدات
sysmedic schedule daily                # فحوص متابعة مجدولة
